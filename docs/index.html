VaxLink

Workplace vaccination · Android app

VaxLink workplace vaccination, installable on your Android phone

Run and join workplace vaccination campaigns end to end — employees sign up with a mobile number, clinicians screen and record each dose, and everyone keeps their own vaccine record. This page installs the app and lists every repository behind the platform.

Download VaxLink APK Open in a browser

Android 8.0+ · ai.vaxlink.app · v2.0 · ~2.4 MB · runs on Chrome (Trusted Web Activity) · preview build with synthetic data

Install in four steps

Sideloading the app

The app isn’t on the Play Store yet, so you install the APK directly. Do these on the Android phone itself.

1

Open this page on your phone

Browse to this page in Chrome on the Android device, then tap Download VaxLink APK above.

2

Allow the install

Android will ask to allow installs from this source the first time. Tap Settings → turn on Allow from this source, then go back.

3

Install

Open the downloaded vaxlink.apk (from the notification or your Downloads) and tap Install.

4

Launch VaxLink

Open the new VaxLink icon. The app loads the live service in Chrome’s engine, so it stays up to date automatically.

Installed an earlier version? This release is signed with a new key, so uninstall the old VaxLink app first, then install this one.

Signing in

How to get in

EmployeesSign up with your mobile number — a one-time SMS code. No company email needed.
HR & clinic teamsSign in with your email address and password.
Sign in with GoogleWorks in the app too — it runs on Chrome’s engine, so Gmail sign-in is fully supported.

Preview build. VaxLink is a preview with synthetic sample data. Please use made-up details — don’t enter real personal or health information.

Behind the platform

All VaxLink repositories

Eighteen repositories across the app, the Go microservices and the infrastructure. All are private source; the summaries below describe what each contains.

Apps & frontend

3 repos
vaxlink-androidAndroid · TWApublic

This repo. An Android app that runs the live web app as a Trusted Web Activity — the real Chrome engine, so Gmail sign-in works — plus the Capacitor build and this install page.

vaxlink-mvp1TypeScriptprivate

The MVP monorepo and canonical home of the React/Vite web app (apps/web), the @vaxlink/ui design system, @vaxlink/contracts, and the Postgres schema/migrations/seed.

vaxlink-webTypeScriptprivate

The web app extracted into its own repo — apps/web plus the contracts and ui packages.

Backend — Go microservices

12 repos
vaxlink-gatewayGoprivate

The single /api entry point. Verifies each request’s bearer token (Firebase ID token or custom session), adds security headers, and dispatches to the services.

vaxlink-identityGoprivate

Authentication and accounts: HR/clinic email+password, employee mobile OTP, sessions, organisations, memberships and roles.

vaxlink-campaignGoprivate

HR campaigns: create, the public campaign landing page, share links and QR codes, and enrollment.

vaxlink-vaxportGoprivate

The employee-owned vaccine record (“Vaxport”): health profile and vaccine history, protected by row-level security.

vaxlink-screeningGoprivate

Pre-vaccination screening questionnaires and the clinical flags they raise (row-level-security protected).

vaxlink-schedulingGoprivate

Slots, bookings, attendance and day-of check-in for each campaign.

vaxlink-clinicalGoprivate

The clinician workflow: patient evaluation, administration records, deferrals, observation and reaction recording, and home-care.

vaxlink-certificateGoprivate

Issues vaccination certificates and powers the public QR verification page (/verify/<code>), exposing only the minimum needed to verify.

vaxlink-notificationGoprivate

Outbound messages (OTP codes, appointment reminders). Fails closed in production rather than claiming a message was sent.

vaxlink-reportingGoprivate

HR funnels and CSV export — participation, schedule, attendance and completion, never the health answers.

vaxlink-supportGoprivate

Support ticketing: raise, assign and resolve tickets with messages and file attachments, with owner-vs-agent access control.

vaxlink-auditGoprivate

An append-only audit log that records every sensitive action across the platform.

Platform, data & infrastructure

3 repos
vaxlink-sharedGoprivate

The shared Go library every service imports: service kit (HTTP, row-level-security transactions, inter-service calls, audit), contracts, DB migrations and the migrate/seed commands.

vaxlink-infraOpenTofuprivate

Infrastructure as code for the live Google Cloud estate — Cloud Run services, Cloud SQL, Artifact Registry, Cloud Storage, Secret Manager and IAM.

vaxlinkDocsprivate

The platform architecture and design reference for VaxLink.
